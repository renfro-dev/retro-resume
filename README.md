# Retro Resume

The source for [renfro.dev](https://renfro.dev): a personal site that presents a career as a retro arcade experience, alongside essays, AI research briefs, and a curated video feed.

**Live:** [renfro.dev](https://renfro.dev) · [retro-resume.vercel.app](https://retro-resume.vercel.app)

## What's on the site

| Route | What it is |
|-------|------------|
| `/` | About page and services |
| `/bio` | The retro resume: rhombus-shaped career chapters and a Pong game that reveals contact details as you score |
| `/research` | Essays and weekly/monthly AI briefs, rendered from markdown in `client/src/content/` |
| `/posts/:slug` | A single essay or brief |
| `/brands` | Brand portfolio (under construction) |
| `/vibetube` | AI videos pulled from newsletters, classified by topic (see [vibe-tube](https://github.com/renfro-dev/vibe-tube)) |

The research briefs are generated by [frontier-research-ai](https://github.com/renfro-dev/frontier-research-ai).

## Tech stack

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui, Framer Motion, Wouter
- **Backend:** Express (local dev) and a bundled Vercel serverless function (production)
- **Data:** Supabase for the video feed; markdown files for essays and research
- **APIs:** Gmail and YouTube Data API for video ingestion, Gemini for classification

## Run it locally

Requires Node.js 20+.

```bash
git clone https://github.com/renfro-dev/retro-resume.git
cd retro-resume
npm install
cp .env.example .env   # then fill in the values below
npm run dev
```

The app runs at `http://localhost:5000`.

### Environment variables

The resume, essays, and research pages work without any keys. The variables below are only needed for the VibeTube feed.

| Variable | Used for |
|----------|----------|
| `VITE_SUPABASE_URL` | Supabase project URL |
| `VITE_SUPABASE_ANON_KEY` | Supabase anon key (browser) |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase service key (server only) |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REFRESH_TOKEN` | Gmail API access; `scripts/get-refresh-token.mjs` generates the refresh token |
| `YOUTUBE_API_KEY` | Video metadata |
| `GOOGLE_API_KEY` | Gemini classification |
| `PORT` | Dev server port (default `5000`) |

## Scripts

| Command | What it does |
|---------|--------------|
| `npm run dev` | Start the dev server with hot reload |
| `npm run check` | Type-check with `tsc` |
| `npm run build` | Build the client, the Express server, and the Vercel API bundle |
| `npm start` | Run the production build |
| `npm run clean` | Remove build artifacts |

## Project structure

```
client/
  src/pages/        Route components
  src/components/   Pong game, chapter cards, VibeTube UI, shadcn/ui
  src/content/      Essays and research briefs (markdown + index.json)
server/             Express app, newsletter routes, Gmail/YouTube/Supabase clients
src/api/            Entry point bundled to api/index.js for Vercel
shared/             Types shared between client and server
attached_assets/    Images used by the resume chapters
```

## Publishing an essay

Add a markdown file to `client/src/content/essays/` named `YYYY-MM-DD-HHMM-slug.md`, add its entry to `index.json` in the same folder, and push to `main`.

## Deployment

Deployed on Vercel. `vercel.json` builds the client to `dist/public`, routes `/api/*` to the serverless bundle, and falls back to `index.html` for client-side routes.
